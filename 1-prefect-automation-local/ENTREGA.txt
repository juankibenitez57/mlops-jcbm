INSTRUCCIONES DE EJECUCIÓN
---------------------------
1. Copiar .env.example a .env y rellenar WANDB_API_KEY

2. Instalar dependencias:
   uv sync
   (o: pip install -r requirements según entorno)

3. Subir dataset a W&B (solo primera vez):
   python wandb_init.py

4. Opción A — Servidor local:
   prefect server start          (terminal 1)
   python deploy_flows.py        (terminal 2, despliega los 3 flows)

   O ejecución directa:
   python f01_monolith.py
   python f02_decoupled.py

5. Opción B — Docker Compose:
   docker compose up -d
   python deploy_flows.py
