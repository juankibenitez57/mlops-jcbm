INSTRUCCIONES DE EJECUCIÓN
---------------------------
Ver SETUP.md para configuración completa. Resumen:

  1. Copiar .env.example a .env y rellenar WANDB_API_KEY, RUNPOD_API_KEY, DOCKER_PAT
  2. uv sync
  3. Levantar Prefect:
       prefect server start  (terminal 1)
  4. Ejecutar los flows en orden:
       python f01_build.py      # construye y sube imagen de entrenamiento
       python f02_train_pod.py  # lanza pod de entrenamiento en RunPod
       python f03_deploy.py     # despliega modelo como serverless
     O desplegar todos con una sola ejecución:
       python deploy_flows.py
  5. Con Docker Compose:
       docker compose up -d
       python deploy_flows.py

NOTA SOBRE CPU vs GPU
---------------------
La API REST de RunPod (/v1/pods) no soporta pods CPU puros mediante API;
requieren creación manual via UI. Se usó NVIDIA RTX A4000 (GPU más económica
disponible). El entrenamiento de Titanic con RandomForest dura < 1 segundo,
por lo que el coste total del pod fue < 0.01 USD.
